# Art

The icon (`icon.svg`), the README banner (`banner.html`) and the settings tool's banner strip (`strip.html`), drawn
as HTML / SVG and rendered to PNG with a browser (1280x320 and 1344x120). The text uses the Cinzel and Cinzel
Decorative fonts (SIL Open Font License, e.g. from Fontsource); put their `woff2` files in a `fonts` folder here.

The rendered files are `media/banner.png`, `media/icon.png`, and in `src/launcher`: `nox-modernized.ico` and
`banner_strip.bmp` (built into the settings tool).
