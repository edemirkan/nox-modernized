# Changelog

## v0.10.0

- Gamepad attack repeats while held. Adjust its interval with `[pad] attack_repeat_ms` (default: `500` ms).
- Build locally with Docker using `src/docker-build.sh`.
- GitHub Actions builds and packages Windows binaries on pushes and releases, and publishes the package to GitHub Releases.
